# Inception — User Guide

## What this is

A small WordPress site, served over HTTPS, split into three containers:

| Service     | Role                                               |
|-------------|-----------------------------------------------------|
| `nginx`     | the only entrypoint; terminates TLS on port 443      |
| `wordpress` | runs WordPress via php-fpm (no web server inside)    |
| `mariadb`   | the WordPress database (no web server inside)        |

They talk to each other over a private docker network; only nginx's port
443 is exposed to the host.

## Starting and stopping

From the repo root, on the VM:

```sh
make init   # first time only: creates srcs/.env and secrets/
make        # builds the images and starts everything (same as `make all`)
make down   # stops and removes the containers
make stop   # stops the containers without removing them
make logs   # follow logs from all three services
make ps     # see container status
```

## Accessing the site

Add this to `/etc/hosts` on the machine you're browsing from (the VM itself,
or your host if you're forwarding the port):

```
127.0.0.1   egokce.42.fr
```

Then visit: **https://egokce.42.fr**

The certificate is self-signed, so your browser will warn you — accept the
exception to continue.

## Admin panel

**https://egokce.42.fr/wp-admin**

- Admin username: value of `WP_ADMIN_USER` in `srcs/.env`
- Admin password: contents of `secrets/wp_admin_password.txt`

A second, non-administrator account also exists:

- Username: value of `WP_USER` in `srcs/.env`
- Password: contents of `secrets/wp_user_password.txt`

## Where credentials live

All passwords are generated by `make init` into the `secrets/` directory
(one file per secret, e.g. `secrets/wp_admin_password.txt`). They are never
written into any Dockerfile, compose file, or committed to git.

## Checking that everything is running

```sh
make ps
```

All three services (`mariadb`, `wordpress`, `nginx`) should show `Up` (and
`healthy` for mariadb). You can also check each container directly:

```sh
docker ps
docker logs nginx
docker logs wordpress
docker logs mariadb
```
